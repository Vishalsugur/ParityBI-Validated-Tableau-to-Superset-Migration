# Tableau: the legacy dashboard

In this project Tableau plays the **existing dashboard being migrated away from**. It reads the CSV extract the pipeline writes to `exports/tableau/incidents.csv`, the same rows Superset reads from PostgreSQL.

## Option A: open the ready-made workbook

`tableau/ServiceDesk_Legacy.twbx` is a packaged workbook: workbook plus data in one file.

1. Install **Tableau Public** (free) or Tableau Desktop. Students can get a free Tableau Desktop licence through Tableau's academic programme.
2. Open `tableau/ServiceDesk_Legacy.twbx`.
3. Open the dashboard tab **Service Desk Overview (legacy)**.

The workbook is generated by `tableau/build_workbook.py` from the latest extract. To refresh it after a pipeline run:

```bash
python tableau/build_workbook.py
```

> If your Tableau version reports an error when opening the generated workbook, build it by hand with Option B. That takes about 30 minutes and produces the same result.

## Option B: build it yourself (about 30 minutes)

### 1. Connect to the data

**Connect → To a File → Text file** → `exports/tableau/incidents.csv`. Check that `opened_week_start` is recognised as a **Date** and `opened_at` as **Date & Time**. If not, change the type with the icon above the column.

### 2. Create the calculated fields

**Analysis → Create Calculated Field**. Names must match exactly, because the validation reads them:

| Name | Formula | Number format |
|---|---|---|
| `Incidents` | `COUNT([incident_number])` | Number, 0 decimals |
| `Resolved incidents` | `SUM([is_resolved])` | Number, 0 decimals |
| `Median resolution (h)` | `MEDIAN([resolution_hours])` | Number, 2 decimals |
| `SLA met (%)` | `100 * SUM([made_sla]) / COUNT([incident_number])` | Number, 2 decimals |
| `First-contact resolution (%)` | `100 * SUM([is_first_contact_resolution]) / COUNT([incident_number])` | Number, 2 decimals |
| `Knowledge used (%)` | `100 * SUM([knowledge_used]) / COUNT([incident_number])` | Number, 2 decimals |
| `Reopen rate (%)` | `100 * SUM([is_reopened]) / COUNT([incident_number])` | Number, 2 decimals |
| `Avg reassignments` | `AVG([reassignment_count])` | Number, 2 decimals |

### 3. Build the sheets

| Sheet | Columns | Rows | Marks |
|---|---|---|---|
| 6 KPI tiles: `Incidents`, `Median resolution (h)`, `SLA met (%)`, `First-contact resolution (%)`, `Reopen rate (%)`, `Avg reassignments` | – | – | Text: the KPI field |
| `Incidents per week` | `opened_week_start` (Exact Date, continuous) | `Incidents` | Bar |
| `Median resolution per week` | `opened_week_start` (Exact Date, continuous) | `Median resolution (h)` | Line |
| `SLA met per week` | `opened_week_start` (Exact Date, continuous) | `SLA met (%)` | Line |
| `SLA met by priority` | `priority` | `SLA met (%)` | Bar |
| `Top 10 categories` | `Incidents` | `category_top10` | Bar |
| `KPI Validation` | `Measure Names` | `opened_week_start` (Exact Date, **discrete**) | Text: `Measure Values`, keep only the 8 KPI fields |

Use `opened_week_start`, **not** `WEEK(opened_at)`. Tableau's week start depends on your locale (Sunday in the US), while the warehouse and Superset use Monday, so every weekly number would shift. The validation would catch it; this avoids it.

`category_top10` already contains the top 10 categories prefixed with their rank (`01 Category 42` …) plus `11 Other categories`, so an alphabetical sort is a sort by volume.

### 4. Assemble the dashboard

New dashboard, size 1400 × 1000: title on top, the 6 KPI tiles in a row, then the three weekly charts, then *SLA met by priority* and *Top 10 categories*. Name it **Service Desk Overview (legacy)**.

## Publish to Tableau Public

**File → Save to Tableau Public As…** (sign in or create a free account). You get a public link to put on your CV or LinkedIn. Tableau Public stores the data as an extract automatically.

## Validate Tableau against the new stack

1. Open the sheet **KPI Validation**.
2. Export it: **Worksheet → Export → Crosstab to Excel**, then save as CSV (Tableau Desktop / Public app), or **Download → Crosstab → CSV** (Tableau Public website / Server).
3. Save as `validation/tableau_export.csv` and trigger the Airflow DAG.
4. Check the *Migration QA & Data Health* dashboard: rows with *Compared with = tableau_export* now appear. All must say **PASS**.

German and English number and date formats are both read correctly.
